# 📚 Laboratory Works in C++

This folder contains laboratory works completed during the 2nd year in **C++ programming language**.

## 📋 Implemented Topics

| Lab | Topic | Description |
| :---: | :--- | :--- |
| **1** | Classes and Objects | Implementation of a class for working with a one-dimensional integer array |
| **2** | Custom String Class | Independently written `String` class with implementation of all main methods |
| **3** | Inheritance | Implementation of class inheritance hierarchy |
| **4** | Custom Container | Independently written `Ring` container (circular buffer) |
| **5** | Exception Handling | Implementation of custom exception handling mechanisms |
| **6** | File I/O | Working with text and binary files |
| **7** | STL Containers & Algorithms | Working with STL containers; implementation of search and sorting algorithms |
