## 📖 What I Learned

Through these projects, I gained practical experience in:

- **Object-Oriented Programming:** classes, inheritance, polymorphism, encapsulation
- **Memory Management:** dynamic allocation, copy constructors, destructors
- **Operator Overloading** and custom class implementation (including a custom `String` class)
- **Custom Containers:** independent implementation of a "Ring" container
- **Exception Handling** and writing exception-safe code
- **File I/O:** text and binary stream processing
- **Standard Template Library (STL):** containers, search and sorting algorithms
- **GUI Development** with the Qt framework
- **Mathematical Modeling** and its integration into a desktop application

---

These projects laid the foundation for further growth in backend development and working with complex software systems.
